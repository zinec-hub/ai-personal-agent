# AI Personal Agent 项目总结 v2.0

> 日期：2026-07-21  
> 技术栈：FastAPI + React + DeepSeek + ChromaDB + Cloudflare Tunnel

---

## 一、项目概述

基于 FastAPI + React 的全栈 AI 个人网站，核心是一个智能 Agent，能够自动判断用户问题类型并选择合适的处理方式：

- **简历相关问题** → 知识库 RAG 检索（三层架构：FAQ + Metadata + 知识库文档）
- **其他问题** → SearXNG 联网搜索 + LLM 分析
- **搜索不可用时** → LLM 直接回答

部署方面通过 Cloudflare Tunnel 实现一键公网访问，无需服务器、无需域名备案。

## 三、核心模块

### 3.1 知识库三层架构（RAG）

#### 第一层：FAQ（常见问答）
- 7 条高频问答对，嵌入问题文本作为检索 key
- 用户提问与 FAQ 问题做语义匹配，命中后直接返回预写答案
- 典型命中率：相似度 0.60~0.78

#### 第二层：Metadata（结构化元数据）
- `resume_metadata.json` 存储结构化信息：
  - 基本信息（姓名、联系方式）
  - 教育经历（学校、专业、课程）
  - 技能标签（编程语言、框架、AI 领域分类）
  - 项目经历（4 个项目，含技术栈、核心亮点）
- 支持精确字段查询和类型过滤

#### 第三层：知识库文档（Markdown）
- Markdown 感知分块：按 `##` 章节标题切割，保留层级路径
- 每个 chunk 注入上下文标题（如 `[## 项目经历 > ### 公司 | 岗位]`）
- 项目章节特殊处理：按 `**项目X**` 标记独立分块
- 所有 chunk 打 `chunk_type` 标签：faq / basic_info / education / project / skill / academic / self_eval

### 3.2 Markdown 感知分块

```
# 普通分块（旧）：
"传统方式下，学生微调模型需手动配置环境..."  ← 不知道属于哪个章节

# Markdown 感知分块（新）：
[## 项目经历 > ### 合肥数模智能科技有限公司 | AI开发工程师]
**项目一：《大模型一体机》**
**背景：** 传统方式下，学生微调模型需手动配置环境...
```

### 3.3 ChromaDB 向量检索

- **嵌入模型**：paraphrase-multilingual-MiniLM-L12-v2 (384维)，本地运行
- **向量数据库**：ChromaDB，持久化存储，余弦距离（`hnsw:space: "cosine"`）
- **检索**：Top-K=6，FAQ 优先匹配
- **路由阈值**：相似度 >= 0.35 判定为简历问题
- **变更检测**：启动时对比文件列表，自动触发索引重建

### 3.4 联网搜索

- **主方案**：SearXNG (Docker 部署)，聚合 Bing/Google/Baidu/Wikipedia
- **备选**：DuckDuckGo
- **兜底**：搜索全部失败时 LLM 直接回答

### 3.5 LLM 集成

- 使用 DeepSeek API (OpenAI 兼容接口)
- 模型：deepseek-v4-pro，max_tokens=16384
- 流式输出 + SSE 推送到前端

### 3.6 前端功能

- 全中文界面，DeepSeek 风格浅色主题
- 对话历史侧边栏（新建/切换/删除）
- Markdown 渲染 + 代码高亮 + 复制按钮
- 流式打字动画 + 自动滚动
- 欢迎页建议问题 + 功能卡片
- 侧边栏 PDF 简历下载
- 状态栏：连接状态 + Agent 模式标签（RAG/Web/LLM）
- 输入框模式切换：Auto / Resume / Search

## 四、遇到的问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 启动卡死 | huggingface.co 被墙，模型加载超时 | local_files_only 优先，HF_ENDPOINT 设镜像 |
| RAG 相似度极低（0.025） | ChromaDB 默认 L2 距离，未设 hnsw:space | 统一使用 `_get_collection()` 确保 cosine 距离 |
| PDF 中文乱码 | PyMuPDF 原生提取编码偏差 | OCR 优先策略：RapidOCR 渲染页面为图片后识别 |
| LLM 找不到项目信息 | 分块丢失 Markdown 层级，LLM 不认识上下文 | Markdown 感知分块 + 标题路径注入 |
| FAQ 命中不准 | 纯关键词匹配无法理解语义 | 将 FAQ 问题嵌入向量库，语义相似度检索 |
| 新增文档未识别 | 向量库未重建 | 启动时对比文件列表（含 .md/.json），自动重建 |
| 公网部署复杂 | ngrok 国内不稳定 | Cloudflare Tunnel，免费、一行命令 |
| start.bat 乱码 | chcp/title 在 bash 不兼容 + 中文编码 | 移除 chcp/title，使用纯 ASCII |

## 六、启动流程

1. 安装 Docker Desktop，启动 SearXNG：
   ```bash
   docker compose -f searxng/docker-compose.yml up -d
   ```
2. 配置 `.env`：DeepSeek API Key + `CLOUDFLARE_AUTO_START=true`
3. 放入知识库文件：`markdown/*.md` + `markdown/resume_metadata.json`
4. 将简历 PDF 放入 `pdf/` 目录（供下载）
5. 安装依赖并构建前端：
   ```bash
   pip install -r backend/requirements.txt
   cd frontend && npm install && npm run build && cd ..
   ```
6. 启动：
   ```bash
   start.bat
   # 或: uvicorn backend.main:app --host 0.0.0.0 --port 8000
   ```
7. 后端窗口显示 Cloudflare 公网地址，浏览器打开即可

## 七、API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 + RAG 统计 |
| GET | `/api/config` | 前端配置（欢迎语、建议问题） |
| POST | `/api/chat` | **核心接口**：SSE 流式对话 |
| POST | `/api/rag/query` | 直接 RAG 检索（无 LLM） |
| GET | `/api/rag/stats` | RAG 索引统计 |
| POST | `/api/rag/rebuild` | 强制重建索引 |
| GET | `/api/pdf/list` | 列出可下载 PDF |
| GET | `/api/pdf/download/{filename}` | 下载指定 PDF |
