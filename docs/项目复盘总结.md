# AI Personal Agent 项目复盘总结

> 日期：2026-07-14  
> 技术栈：FastAPI + React + DeepSeek + ChromaDB + Cloudflare Tunnel

---

## 一、项目概述

基于 FastAPI + React 的全栈 AI 个人网站，核心是一个统一 Agent，能够自动判断用户问题类型并选择合适的处理方式：

- **简历相关问题** → RAG 检索 + LLM 生成
- **其他问题** → SearXNG 联网搜索 + LLM 分析
- **搜索不可用时** → LLM 直接回答

部署方面通过 Cloudflare Tunnel 实现一键公网访问，无需服务器、无需域名备案。

## 三、核心模块

### 3.1 PDF 处理与 OCR

- 使用 PyMuPDF (fitz) 解析 PDF
- 对扫描版 PDF 自动启用 RapidOCR (ONNX Runtime) 识别中文
- 支持多份 PDF 简历同时加载，启动时自动检测变化并重建向量库

### 3.2 RAG 向量检索

- **嵌入模型**：paraphrase-multilingual-MiniLM-L12-v2 (384维)，本地运行
- **向量数据库**：ChromaDB，持久化存储
- **分块策略**：按段落+句子递归分割，chunk_size=500，overlap=50
- **检索**：余弦相似度，Top-K=4 返回最相关片段
- **路由阈值**：相似度 >= 0.35 判定为简历相关问题

### 3.3 联网搜索

- **主方案**：SearXNG (Docker 部署)，聚合 Bing/Google/Baidu/Wikipedia
- **备选**：DuckDuckGo
- **兜底**：搜索全部失败时 LLM 直接回答
- SearXNG 解决了国内无法访问 Google/DuckDuckGo 的问题

### 3.4 LLM 集成

- 使用 DeepSeek API (OpenAI 兼容接口)
- 模型：deepseek-v4-pro，max_tokens=16384
- 流式输出 + SSE 推送到前端

### 3.5 前端

- 浅色主题，DeepSeek 风格
- Markdown 渲染 (react-markdown + remark-gfm)
- 代码块复制按钮
- 欢迎页建议问题
- 流式打字动画

## 四、遇到的问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 启动卡死 | huggingface.co 被墙，模型加载超时 | 优先 local_files_only 从缓存加载，HF_ENDPOINT 设镜像 |
| OCR 失败 | `_init_ocr_engine()` 缺少 `global _ocr` 声明 | 添加 global 声明，变量正确赋值 |
| 搜索不可用 | DuckDuckGo 在国内被限制 | 部署 SearXNG 代理 Bing/Baidu，失败回退 LLM 直接回答 |
| LLM 输出截断 | max_tokens=2048 不够 | 提升至 16384 |
| 输出 500 错误 | `cd backend` 后模块路径解析错误 | start.bat 从项目根目录执行 uvicorn |
| 新增 PDF 未识别 | 向量库未重建 | 启动时自动对比 PDF 文件列表，变化时自动重建 |
| 公网部署复杂 | ngrok 国内不稳定 | 换成 Cloudflare Tunnel，免费、无需注册、一行命令 |
| start.bat 乱码 | UTF-8 中文在 GBK cmd 下乱码 | 改为纯英文 ASCII |

## 六、启动流程

1. 安装 Docker Desktop，启动 SearXNG：`docker compose -f searxng/docker-compose.yml up -d`
2. 配置 `.env`：DeepSeek API Key + `CLOUDFLARE_AUTO_START=true`
3. 把简历 PDF 放入 `pdf/` 目录
4. 运行 `start.bat`
5. 后端窗口显示 Cloudflare 公网地址，浏览器打开即可
